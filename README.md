# ❌⭕ Крестики-Нолики на Pygame

Классическая игра «Крестики-нолики», написанная на Python с графическим интерфейсом на библиотеке **Pygame** и удобным управлением через **терминал**.

## 🚀 Особенности
- **Игра до 3 побед:** Ведётся счёт раундов, пока один из игроков не наберёт 3 очка.
- **Интерактивное меню:** Выбор действий и отображение счёта прямо в терминале.
- **Быстрый перезапуск:** Возможность сбросить текущий раунд нажатием клавиши `R`.
- **Минималистичный дизайн:** Лаконичный внешний вид и плавный игровой процесс.

## 🛠️ Требования и запуск
Для работы игры требуется установленнный Python 3 и библиотека Pygame:

```bash
pip install pygame
python main.py
